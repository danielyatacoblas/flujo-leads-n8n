Configuración

A dónde se manda el formulario.
Modo simulado (sin n8n)
Levantar n8n en tres pasos:
  1. docker compose up -d
  2. Importa workflows/workflow_leads_demo.json y actívalo
  3. Pulsa «Usar el n8n local»

Modo prueba: en n8n abre el workflow y pulsa Execute workflow. Queda esperando una llamada y, al enviar el formulario, el lienzo se anima mostrando los datos pasar por cada nodo. Solo escucha un envío por vez: vuelve a pulsarlo para el siguiente.

Sin URL configurada, el formulario corre en modo simulado: aplica la misma lógica dentro del navegador para que veas el resultado igual.
